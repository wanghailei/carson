**What changes**

- Every line Carson writes starts with ⧓, so its words stand out in an agent's conversation, as in Carson 4.
- Every message says what happened, why, and what to do next. Each failure names the command to run again once its cause is cleared, and a refusal of another session's task says to leave it to that session, or when a person must settle it.
- Carson says nothing in the agents' private language any more: what only a person can settle is said to be a person's.
- `bin/check` runs with plain `go` as well as through mise, so anyone can run the checks.
- The README is written for Carson's users.

No command changes.

**Install**

Download the build for your system below, unpack it, and put `carson` on your PATH. `checksums.txt` holds each download's SHA-256.
